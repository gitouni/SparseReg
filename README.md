# Marker-Markerless Tactile Transition
Official Implementation of the paper `Marker or Markerless? Mode-Switchable Optical Tactile Sensing for Diverse Robot Tasks`

This repo is about Markerless-Marker Transition.

* Markerless-Marker Transition: Switch to the `markerless-to-marker` branch
* Marker-Markerless Transition: Switch to the `marker-to-markerless` branch

* Robot Arm Ur5e Control Code: [https://github.com/gitouni/gripper_ctrl](https://github.com/gitouni/gripper_ctrl)
